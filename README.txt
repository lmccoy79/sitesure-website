IMPORTANT BEFORE LAUNCH
1. Create a free Formspree account and create a form that sends notifications to latasha@sitesurecleaning.com.
2. Formspree will give you an endpoint similar to https://formspree.io/f/abcxyzde.
3. Replace BOTH occurrences of https://formspree.io/f/YOUR_FORM_ID in assessment.html and contact.html with the real endpoint.
4. Test both forms before launch.
5. Host the files using GitHub Pages or another static host.
6. Connect sitesurecleaning.com as the custom domain.
7. Turn on/enforce HTTPS after DNS has verified.

No hosting subscription is required for this static website if you use GitHub Pages free hosting.
